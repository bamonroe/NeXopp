# `.rnote` format fixtures

Ground-truth [Rnote](https://github.com/flxzt/rnote) save files, **generated by
`rnote-cli` 0.14.2 — never hand-authored** — for the `.rnote` support work. Each
one mirrors the `.xopp` fixture of the same name in the parent directory (see its
`README.md` for what each covers), so the same document can be compared across
both formats.

| Fixture             | Source                          |
|---------------------|---------------------------------|
| `plain.rnote`       | `../plain.xopp`                 |
| `backgrounds.rnote` | `../backgrounds.xopp`           |
| `layers.rnote`      | `../layers.xopp`                |
| `text-image.rnote`  | `../text-image.xopp`            |
| `empty.rnote`       | `rnote-cli create` (empty document) |

Every file passes `rnote-cli test`. The commands to regenerate and validate them
live in [`docs/tools.md`](../../../../../../docs/tools.md#rnote-cli) — that is the
authoritative home for the tool itself.
